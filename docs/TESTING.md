# דוח סבב התיקונים — 07.10.2026

## סביבה ותוצאות

Windows, Node.js 24.20.0, npm 11.19.0, Expo SDK 57.0.27, React Native 0.86.3. שרת הפיתוח: `npx expo start --web`, כתובת `http://localhost:8081/`. בדיקות UI בוצעו בדפדפן המובנה של Codex עם מתאם React Native Web.

| בדיקה | תוצאה | משמעות |
| --- | --- | --- |
| `npm run typecheck` | עבר | טיפוסים לכל קוד האפליקציה והבדיקות |
| `npm run lint` | עבר ללא אזהרות | כללי React/Expo כולל hooks |
| `npm test` | 29/29 עברו | כללי דומיין, שדרוג נתונים, שמירה, יומנים וחישובים |
| `npm run export:native` | עבר, iOS ו־Android עם Hermes | פתרון imports ו־assets ויצירת bundles לשתי הפלטפורמות |
| UI Web | עבר בתרחישים המפורטים בהמשך | זרימת שימוש ונתונים בדפדפן בלבד |
| iPhone / iOS Simulator | לא נבדק | אין הוכחת runtime native |
| Android / Android Emulator | לא נבדק | אין הוכחת runtime native |
| VoiceOver / TalkBack | לא נבדק | התוויות והמבנה קיימים בקוד; נדרש מכשיר |

ייצוא ה־native אינו APK/IPA או קומפילציה/הרצה של אפליקציה חתומה. לא נבדקה סגירת תהליך Expo Go במכשיר. `expo-doctor` ו־audit לא הורצו מחדש בסבב זה; תוצאותיהם הקודמות נמצאות ב־README.

## תרחישי דפדפן שבוצעו

הפרופיל המקורי נשאר ב־`localhost:8081`. בדיקות יצירה, עריכה ומחיקה נעשו ב־`127.0.0.1:8081`, מקור דפדפן נפרד, עם נתוני QA מלאכותיים. הן אינן דוגמאות שנטענות מראש למשתמש.

### שדרוג ושמירה

- הפרופיל הקיים ״בדיקת פיטלי״ נטען אחרי השדרוג והרענון, עם מטרה/סוג אימון ומראה קיימים ושתי המדידות המקוריות. משתמש חוזר הגיע ל״היום״. שדות פיזיולוגיים שלא היו בגרסה הקודמת נשארו חסרים, ולא נוצר יעד קלורי מומצא.
- פרופיל QA נוצר כאישה, 35, גובה 165, משקל 70, פעילות נמוכה. טיוטת שלב היעדים נשמרה ונטענה לאחר רענון.
- שונו שם, נתון גבר/אישה, מטרה וסוג אימון ונבנו שלוש גרסאות תוכנית. היסטוריית המדידות ורישום הריצה נשארו. יעד היום המקורי נשאר 1,953.4 קלוריות (1,953 בתצוגה), בעוד תוכנית גבר חדשה הציעה אומדן תחזוקה 2,185.8 לימים חדשים.
- נשמר מראה גברי/שיער קצר, אחרי מראה נשי/קארה. מזהה הפרופיל, מדידות, ביצוע ריצה ויעד יומי לא השתנו. הוצג אישור שמירה בממשק.
- לשונית QA נסגרה, נוצרה לשונית חדשה ונפתחה אותה כתובת. חזרה ל״היום״ ללא שאלון מחדש, עם אותו שם/יעד, שתי מדידות וריצה אחת. מזהה הפרופיל והדמות נשמרו. זו **סגירת לשונית**, לא כיבוי דפדפן או תהליך אפליקציה בטלפון.

### שלושת מסלולי האימון

- כוח בלבד + ירידה בשומן: לא הופיעו יעדי ריצה; נבנתה מסגרת כוח ומנוחה. יום מנוחה הוצג כחלק מהתוכנית.
- ריצה: הוגדרו יעד 5 ק״מ, 6:30 לק״מ, 31/12/2026; יכולת 3 ק״מ ב־21 דקות; הליכון ושיפוע 1. הוצג קצב נוכחי 7:00 ומהירות 8.6 קמ״ש.
- משולב + שינוי הרכב גוף: נבחרה ריצה בחוץ ונבנתה מסגרת עם כוח, ריצה ומנוחה. משקל יעד נשאר אופציונלי ונפרד. ביצוע הריצה מהתוכנית הקודמת נשאר ריצה, ולא הומר לכוח.
- פתיחת אימון לא הוסיפה רישום. שמירת ביצוע ריצה של 21 דקות/3 ק״מ כן הוסיפה רישום אחד ועדכנה את היום והיומן. הקלוריות לא שונו כתוצאה מהריצה.

### ארוחות, קלוריות ומאקרו

- ארוחה: 200 קלוריות, 20 גרם חלבון, 5 שומן, 18 פחמימות. נאכלו 200; יתרה 1,753.4. חלבון: כ־16.4% מהיעד בגרמים, 40% מהקלוריות שנאכלו, מול 25% בתכנון. שומן 22.5% ופחמימות 36% מהצריכה. הסיכום עקבי ביום ובהתקדמות.
- עריכת אותו רישום ל־150 קלוריות ו־15 גרם חלבון השאירה ארוחה אחת; נאכלו 150, יתרה 1,803.4, ושאר האחוזים עודכנו לפי המכנה החדש.
- מחיקה עם אישור החזירה את הצריכה לאפס והיתרה ליעד היום. לא נשארה כפילות. אין אכילה אוטומטית מרעיונות הארוחות.

### מדידות, RFM ועיצוב

- שתי מדידות QA: מותניים 80→78, אגן 100→101, חזה 95→96 וזרוע ימין 30→31. כשמשקל/ירך חסרים באחת הנקודות, אין הפרש או שינוי גוף לאותו שדה.
- בחירת NHANES אפשרה RFM: 22.8% במדידה הראשונה ו־21.7% בשנייה, על בסיס גבר, גיל 35 וגובה 165. שיטה לא ידועה קודם לכן לא קיבלה אומדן.
- דמויות נשית וגברית צולמו ונבדקו באותה זהות, תנוחה וקנה מידה בין שתי הנקודות. הזרוע רציפה מהכתף לכף היד. הכיתוב הנדרש מופיע ליד ההשוואה.
- רוחבי 390×844 ו־320×844: גלילה, RTL, שלוש לשוניות, מעבר השוואה לטור צר וכפתורים. 150% טקסט באפליקציה נבדק ב־320; תוקנו גלישת כותרת ומספר קלוריות. טופס הפרופיל נשאר נגלל ופעולת ההמשך גלויה.
- תצוגת מחשב נבדקה עם מרכז תוכן מוגבל רוחב; המסך הקיים נשמר פעיל. צילומים הם מדפדפן ולא ממכשירי טלפון.
