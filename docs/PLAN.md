# סבב תיקונים — 07.10.2026

התוכנית הקצרה שיושמה:

1. שימור הפרופיל וההיסטוריה באמצעות מזהה קבוע, סכימה 2, גיבוי לפני הגירה וגרסאות תוכנית/יעדים יומיים שאינן משוכתבות.
2. שאלון חמישה שלבים, נתוני חישוב בנפרד מהדמות, שלושה מסלולי אימון ויעדי ריצה ומשקל נפרדים.
3. ניווט היום / התוכנית שלי / התקדמות, מסגרת שבועית עם מנוחה, ופעולות ברורות לרישום ביצוע בפועל.
4. אומדני אנרגיה ומאקרו לפי נתוני הפרופיל, יומני ארוחות ואימונים וסיכום יחיד לכל המסכים. RFM רק עם שיטת מותניים מתאימה וקלט תקף.
5. שפה צבעונית מקורית, אווטאר אנושי בתנוחה קבועה, תמיכה בטקסט גדול ובתנועה מופחתת.
6. בדיקות דומיין ושמירה, בדיקה מעשית בדפדפן ושדרוג הנתונים הקיימים, צילומים, ייצוא native ותיעוד בדיקות טלפון שטרם בוצעו.

## החלטות היקף

- פרופיל מקומי אחד לכל התקנה. חשבונות, סנכרון, AI, חיבורי בריאות וצילום אוכל אינם בהיקף.
- הבקשה הישירה של המשתמש מגדירה את סבב התיקונים. הבריף המצורף שימש הקשר ודרישות מוצר; הצעות למימוש/טכנולוגיה בו אינן אישור להפעלה של שירות חיצוני.
- זמינות, מסלול ויומנים אמיתיים; תוכן תרגילים ורעיונות ארוחות עדיין דוגמאות מסומנות, בהתאם להיקף הפרוטוטייפ בבריף. אין טענה לתפריט או לתוכנית עומסים מקצועיים.
- אנרגיה מחושבת כאומדן תחזוקה או כיעד אישי שהוזן. אין גרעון/עודף אוטומטי לפי מטרה לפני אימות כללים מקצועיים. חלוקות המאקרו הן כללי מוצר ראשוניים בטווחי AMDR; הן אינן מסקנה מחקרית ספציפית לכל מסלול.
- מראה האווטאר אינו משנה נוסחאות. מדידות ישנות עם שיטת מותניים לא ידועה אינן מקבלות RFM בדיעבד.
- בדיקות QA בוצעו במקור דפדפן נפרד (`127.0.0.1`), כדי לא לשנות את הפרופיל הקיים ב־`localhost`.
